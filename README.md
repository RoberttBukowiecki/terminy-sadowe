# terminy-sadowe

Minimalny starter Next.js z App Routerem, TypeScriptem, ESLintem i Prettierem.

## Start

```bash
npm install
npm run dev
```

## Skrypty

- `npm run dev` - lokalny serwer deweloperski
- `npm run build` - build produkcyjny
- `npm run lint` - lint projektu
- `npm run typecheck` - sprawdzenie typow
- `npm run format` - sprawdzenie formatowania
